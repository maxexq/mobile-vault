# Trait cards (MV-483): approved sources and the light reference

Approved by Parames on 2026-10-26 (epic MV-483, frame MV-484, light loops MV-485..496, integration MV-498; visual
tiers MV-497 pending). traits-ui-v1 (the ornate dossier) was rejected and is not used.

- `v2-compact-trait-cards.png`: the accepted compact card density. `v3-trait-rarity-positive-negative.png`: the
  beneficial / trade-off design. `traits-positive-negative-animated.gif` (sha256
  `aef4716a7f17fce183992de844d6380e740363b5d6a5be94d0db66b3cef3df50`) + `animation-poster.png`: the approved v4 motion
  (16 phases, 8 fps, 2 s). `build_preview.py`, `preview-manifest.json`, `approval.json`: the preview builder and record.
- `fx_trait_masks.png` + `.json`: the 192 canonical light masks (12 profiles x 16 phases, 172x70 with the 160x58 card at
  6,6), generated by `tools/art/ui.py` `gen_trait_cards()`. Not shipped: cards size to their text, so the game draws
  the same algorithm for each card's real size (`scripts/ui/trait_fx.gd`); the autotest checks its 160x58 output
  against this sheet pixel for pixel. Keeping the masks out of the atlas keeps it at 2048x2048 on phones.

Only the card frame (`ui_trait_card_frame`) is in the atlas. This folder is not imported by Godot (`.gdignore`).
