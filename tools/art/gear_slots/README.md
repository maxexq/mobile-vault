# Equipment slots (MV-473): approved sources

Approved by Parames on 2026-10-26 (epic MV-473, assets MV-474..480, integration MV-481).

- `v1-equipment-slot-study.png`: the riveted steel slot design.
- `v2-rarity-neon-aura-study.png`: the emissive neon / aura study.
- `all-rarities-neon-aura.gif` (sha256 `4240b7534ef425576f7ce880109abe29bbbc9d91cbc9f7ef3aa52e18a68b5a55`), `animation-poster.png`,
  `aura-contact-sheet-native.png`: the approved v3 animation (16 phases, 8 fps, 2 s loop).
- `build_preview.py`, `preview-manifest.json`, `approval.json`: the preview builder and its record. Its `cell()` is the
  motion reference the production masks follow.

Production art is generated by `tools/art/ui.py` (`ui_gear_slot_frame`, `fx_gear_*`, `gen_gear_slots`) into the atlas:
a steel frame per tile width (28 / 30 / 32 / 36 / 40) and, per rarity and width, 16 light masks in three grey codes
that `shaders/gear_fx.gdshader` colours at runtime. This folder is not imported by Godot (`.gdignore`).
