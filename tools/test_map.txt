# Which autotest groups cover which files (MV-779). Read by tools/ci_select.py.
# One rule per line: <glob> <suite> [<suite> ...]. A suite is an --only=<group> name from tools/autotest.gd,
# "core" (boot + core gameplay walk, --only=core) or "full" (the whole autotest).
# Every matching rule adds its suites. On top of this file ci_select.py also picks, by itself:
#   - groups whose name appears in the path (scripts/autoload/threat.gd -> threat),
#   - groups whose tests mention the file (its res:// path, file name, autoload name or class_name),
#   - for tools/autotest.gd: the groups that run the changed test functions.
# A game file that none of that matches gets "core". Only add rules here for files those heuristics miss
# or over-select (shared files like main.gd, ui_kit.gd). Globs use fnmatch: * also matches "/".
